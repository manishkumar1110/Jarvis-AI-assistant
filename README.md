# JARVIS AI Assistant

JARVIS is a beginner-friendly Python personal assistant project built to practice and apply core Python programming concepts.

## Current Features

* Responds to basic commands
* Displays the current date and time
* Saves personal notes to a text file
* Reads and displays saved notes
* Handles unknown commands
* Runs continuously until the user exits

## Technologies Used

* Python
* `datetime`
* File Handling

## Project Goal

This project is being developed step by step to build a more capable personal assistant. Future versions will include voice interaction, web-based commands, APIs, and AI-powered features.

## Current Status

**Stage 2 — Text-based assistant with note-taking functionality completed.**
